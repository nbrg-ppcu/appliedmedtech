# Session 5: Which cell is it?

Classifying blood cell types and evaluating transfer to new donors and a biobank.

[Student notebook](S5_sccells.ipynb) · [Open in Colab](https://colab.research.google.com/github/nbrg-ppcu/appliedmedtech/blob/session-05-single-cells/notebooks/session_05/S5_sccells.ipynb)

## Materials

- [Lab handout](S5_lab_handout.md)
- [Data dictionary](data/pbmc_DICTIONARY.md)
- [Training data](data/pbmc_train.csv): 4,007 cells from 16 donors
- [Biobank data](data/pbmc_external.csv): 1,533 cells from 6 new donors

Open the notebook in Colab, save a copy in Drive, and run the setup cells in order. The first cell installs NumPy, pandas, and scikit-learn; both datasets load directly from GitHub. A Python CPU runtime is sufficient.

The data are synthetic; no real person is represented.
